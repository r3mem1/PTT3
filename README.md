# Presentation Bot

Telegram-бот, который собирает структуру презентации через LLM (OpenRouter) и отдаёт готовый `.pptx` файл — по текстовой теме или по загруженному Word-документу. Картинки для слайдов ищутся в Pexels.

> Это обновлённая версия по ТЗ из `ТЗ_улучшение_presentation_bot.md`: реализованы модули 2 (меню и настройки), 3 (импорт .docx) и 4 (качество презентаций). **Модуль 1 (безопасность/лимиты/доступ) сознательно не реализован** — бот по-прежнему открыт для любого пользователя Telegram без ограничений. Внедрите модуль 1 перед публичным/боевым использованием.

## Возможности

- Генерация структуры слайдов по теме **или** по загруженному `.docx` документу (краткая выжимка с сохранением структуры заголовков и таблиц).
- Редактируемый черновик: перед сборкой файла из документа можно посмотреть список слайдов и попросить бота доработать структуру свободным текстом.
- Шесть раскладок слайдов: текст, картинка слева/справа, карточки (`cards`), акцент на метрике (`stat`), цитата/секция — модель теперь осознанно чередует все раскладки, а не только текст и картинки.
- Настройки на пользователя (`/settings`): число слайдов, тон (деловой / стартап-питч / учебный / минималистичный), язык вывода (ru/en), тема оформления (тёплая терракотовая / холодная корпоративная / тёмная премиум).
- Опциональный логотип пользователя, который накладывается в угол каждого слайда.
- История последних тем с кнопкой «повторить генерацию».
- Пошаговый статус генерации вместо одного статичного сообщения.
- Единая тема оформления поверх шаблона `templates/template.pptx`, с авто-подгонкой размера шрифта под длинный текст и декоративной геометрией на титульном слайде, если картинка не нашлась.
- Асинхронные запросы к API — бот не блокируется на время генерации.

## Быстрый старт

1. Python 3.11+ (рекомендуется 3.12).
2. Создайте виртуальное окружение и поставьте зависимости:

```powershell
cd presentation_bot
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

На Linux/macOS: `python -m venv venv && source venv/bin/activate && pip install -r requirements.txt`

3. Скопируйте `.env.example` в `.env` и заполните ключи:

```env
TELEGRAM_BOT_TOKEN=...
OPENROUTER_API_KEY=...
PEXELS_API_KEY=...
```

`PEXELS_API_KEY` можно оставить пустым — слайды соберутся без картинок (с декоративным фолбэком на титуле).

4. Запуск:

```powershell
python bot.py
```

При первом запуске автоматически создаётся `output/bot.sqlite3` — хранит настройки пользователей и историю тем (см. `db.py`).

5. В Telegram откройте бота, нажмите `/start` и отправьте тему, например: `Как ИИ меняет маркетинг` — или пришлите `.docx` файл.

## Команды бота

| Команда | Что делает |
| --- | --- |
| `/start` | Приветствие + главное меню |
| `/menu` | Открыть главное меню (та же кнопка «☰ Меню» на клавиатуре) |
| `/settings` | Число слайдов, тон, язык, тема оформления |
| `/help` | Краткая справка |
| `/logo_remove` | Убрать загруженный логотип |
| `/cancel` | Отменить текущее действие (например, ввод своего числа слайдов) |

Логотип загружается через меню «🖼 Логотип» — просто пришлите картинку после нажатия кнопки.

## Как работает импорт Word-документа

1. Пользователь присылает `.docx` (до 15 МБ).
2. `docx_service.py` вытаскивает текст, помечая заголовки (`## `) и разворачивая таблицы в строки — это даёт модели ориентиры по структуре документа.
3. `ai_service.build_prompt_from_document` просит модель сделать **выжимку**, а не пересказ, и вернуть ту же JSON-схему слайдов, что и обычная генерация по теме — поэтому `pptx_builder.py` не пришлось менять для этой фичи.
4. Бот показывает черновик (нумерованный список заголовков слайдов) с кнопками «Собрать», «Доработать», «Отмена».
5. «Доработать» — можно написать правки свободным текстом («убери слайд про историю компании, добавь риски»); модель пересоберёт структуру с учётом документа и правки.

## Зависимости

| Пакет | Зачем |
| --- | --- |
| `aiogram` | Telegram Bot API, включая FSM для меню/настроек/диалога правок |
| `aiohttp` | Асинхронные HTTP-запросы к OpenRouter и Pexels |
| `python-dotenv` | Загрузка `.env` |
| `python-pptx` | Сборка `.pptx` |
| `Pillow` | Пропорции картинок при вставке, размер логотипа |
| `aiosqlite` | Хранилище настроек пользователей и истории тем |
| `python-docx` | Чтение `.docx` для функции «презентация из документа» |

Синхронный `requests` не используется специально: он заморозил бы event loop на время ответа модели.

## Структура проекта

```
presentation_bot/
├── bot.py               # хендлеры Telegram: меню, настройки, документы, генерация
├── config.py             # .env, пути, модель, число слайдов по умолчанию
├── db.py                 # SQLite: настройки пользователей + история тем
├── models.py              # типы, нормализация JSON от ИИ, мягкая обрезка длинных буллетов
├── ai_service.py          # OpenRouter, промпты (по теме и по документу), разбор JSON
├── docx_service.py        # извлечение текста/структуры из .docx
├── image_service.py       # поиск картинок Pexels + эвристика по пропорциям + кеш
├── pptx_builder.py        # сборка презентации: раскладки, темы оформления, логотип
├── theme.py                # цветовые пресеты + раскладочные константы
├── templates/
│   └── template.pptx      # макеты слайдов
├── output/                 # временные файлы и bot.sqlite3 (в .gitignore)
├── .env.example
├── .gitignore
└── requirements.txt
```

## Безопасность

- Храните ключи только в `.env`, не коммитьте его.
- Пользователю не показываются сырые ошибки API (баланс, ключ и т.д.) — они пишутся в лог.
- Не публикуйте репозиторий, если `.env` когда-либо попадал в историю git. Если это случилось — сразу перевыпустите токены у BotFather, OpenRouter и Pexels.
- Напоминание: без модуля 1 бот отвечает любому пользователю Telegram без ограничений — это осознанный компромисс текущей версии, а не забытая деталь.
